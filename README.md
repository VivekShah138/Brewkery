# Brewkery · Android Developer Take-Home Challenge

This repository contains the official landing page and API data payload for the **Brewkery** Android Developer take-home assessment.

- **Hosted Brief & Guidelines**: [https://vivekshah138.github.io/Brewkery/](https://vivekshah138.github.io/Brewkery/)
- **API Endpoint**: `https://raw.githubusercontent.com/VivekShah138/Brewkery/main/data.json`

## Overview
Candidates are invited to build a 4-screen native Android ordering application using modern Kotlin, Jetpack Compose, and AI-assisted workflows.
